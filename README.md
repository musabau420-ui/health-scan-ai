# HEALTH SCAN AI
Adaptive Multimodal Medical AI — Android Flutter prototype.

## Build Android APK
Connect this repository to Codemagic and run the `android-health-scan` workflow.

## Current prototype
- Dashboard with Heart & ECG, Brain & Stroke, Bone & Injury, Blood Analysis, MRI/CT/X-ray and Emergency First Aid modules.
- Bengali-first interface.
- Module placeholder screens.

## Safety
This prototype does not diagnose disease and does not interpret medical images or replace clinicians. Real clinical features require validated data, qualified medical review, privacy/security controls and appropriate medical-device integrations.
